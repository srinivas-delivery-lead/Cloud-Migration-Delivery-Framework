# Cloud Migration Checklist

## Discovery
- [ ] Application inventory completed
- [ ] Business criticality classified
- [ ] Current architecture documented
- [ ] Upstream/downstream dependencies mapped
- [ ] Data classification completed
- [ ] Licensing constraints reviewed

## Assessment
- [ ] Migration strategy selected
- [ ] Cloud-services mapping completed
- [ ] TCO / cost assumptions reviewed
- [ ] Availability and DR requirements captured
- [ ] Security requirements defined

## Design
- [ ] Target architecture approved
- [ ] Network design approved
- [ ] Identity and access model approved
- [ ] Logging and monitoring designed
- [ ] API contracts reviewed
- [ ] Data migration design approved

## Build
- [ ] Infrastructure automation implemented
- [ ] CI/CD pipelines ready
- [ ] Configuration externalized
- [ ] Secrets management implemented
- [ ] Observability enabled

## Test
- [ ] Functional regression complete
- [ ] Integration testing complete
- [ ] Performance testing complete
- [ ] Security testing complete
- [ ] DR / resilience testing complete
- [ ] Data reconciliation complete

## Cutover
- [ ] Runbook approved
- [ ] Go/no-go criteria agreed
- [ ] Rollback plan validated
- [ ] Business communication prepared
- [ ] Support bridge arranged

## Hypercare
- [ ] Monitoring thresholds reviewed
- [ ] Incident ownership confirmed
- [ ] Daily hypercare review established
- [ ] Performance and cost baseline captured
