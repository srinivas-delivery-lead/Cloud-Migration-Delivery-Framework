# API Readiness Checklist

## Contract
- [ ] Endpoint and method defined
- [ ] Request/response schema versioned
- [ ] Error model documented
- [ ] Idempotency requirements defined
- [ ] Pagination / limits documented

## Security
- [ ] Authentication method approved
- [ ] Authorization model tested
- [ ] Secrets stored securely
- [ ] Sensitive data minimized
- [ ] Rate limiting defined

## Reliability
- [ ] Timeout values defined
- [ ] Retry policy documented
- [ ] Circuit-breaker strategy considered
- [ ] Dependency SLAs known
- [ ] Graceful degradation defined

## Testing
- [ ] Positive contract tests
- [ ] Negative tests
- [ ] Performance tests
- [ ] Mock / stub strategy
- [ ] Backward compatibility tests
